## Използвани технологии

- **JavaScript**
- **Node.js** (версия 20 или по-нова)

## Стартиране

Необходимо е да бъде инсталиран Node.js.

1. Създайте файл `input.txt` в директорията на проекта и поставете входните данни в него.
2. Стартирайте програмата:

```bash
node main.js < input.txt
```

Резултатът се извежда на конзолата.
