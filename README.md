# This won third place 🥉!
 
 ## Използвани технологии

- **JavaScript**
- **Node.js** (версия 20 или по-нова)
- **HTML, CSS и JavaScript** (за визуализацията)

## Стартиране

Необходимо е да бъде инсталиран Node.js.

1. Създайте файл `input.txt` в директорията на проекта и поставете входните данни в него.
2. Стартирайте програмата:

```bash
node main.js < input.txt
```

Резултатът се извежда на конзолата.

За да запазите резултата във файл, използвайте:

```bash
node main.js < input.txt > output.txt
```

## Визуализация

1. Стартирайте програмата и запазете резултата във файл `output.txt`, както е описано по-горе.
2. Отворете `visualizer/index.html` в уеб браузър (Възможно е и използването на Live Server extension-a, като тогава трябва да отворите браузър на http://127.0.0.1:5500/vizualizer/index.html).
3. Изберете входния файл `input.txt`.
4. Изберете изходния файл `output.txt`.
5. Натиснете бутона **Visualize**, за да се генерира визуализацията.

Визуализацията показва населените места, разпределението им по региони и граничните пътища между регионите.
